# 基于资金图谱的涉诈账户发现项目——最终交付内容清单

最终交付不能只包含“模型代码和实验结果”，而应形成一套能够让甲方**安装、运行、查看结果、复现实验、核对指标和理解局限性**的完整项目包。

## 一、项目源代码

### 1. 数据处理模块

至少包括：

- 账户表、交易边表、风险标签表读取与字段校验；
- 标签一致性、重复记录、缺失值及异常金额检查；
- 负金额处理、账户 ID 映射和标签编码；
- 训练集、验证集、测试集账户划分；
- 交易观察窗口截断；
- 数据泄露检查；
- 中间数据生成。

建议脚本：

```text
scripts/
├── 01_validate_raw_data.py
├── 02_build_account_dataset.py
├── 03_build_temporal_splits.py
└── 04_check_data_leakage.py
```

### 2. 动态资金图谱构建模块

至少包括：

- 账户节点与交易有向边构建；
- 按月份或时间窗口构图；
- 静态图与动态图统计；
- 孤立账户识别；
- 连通分量分析；
- 社区发现；
- 图谱结果导出。

建议支持：

- 全量资金图；
- 月度资金图；
- 指定账户子图；
- 一跳、二跳、三跳邻域查询；
- 指定时间范围的交易关系查询。

建议脚本：

```text
scripts/
├── 05_build_transaction_graph.py
├── 06_build_temporal_graphs.py
└── 07_generate_graph_statistics.py
```

### 3. 特征工程模块

#### 账户静态特征

- 开户时长；
- 客户类型；
- 地区编码；
- 是否存在交易；
- 是否为孤立节点。

#### 交易行为特征

- 入账次数、出账次数；
- 入账金额、出账金额；
- 净资金流；
- 平均交易金额、最大单笔金额；
- 交易金额波动；
- 活跃天数；
- 交易对手数量；
- 重复交易比例；
- 夜间交易比例；
- 短时间密集交易；
- 收款后快速转出；
- 金额分散度与集中度。

#### 图结构特征

- 入度、出度、总度数；
- PageRank；
- 聚类系数；
- k-core；
- 社区编号与社区规模；
- 二跳邻居数量；
- 风险邻居数量及比例；
- 汇聚、分散和中转特征；
- 双向交易比例。

建议脚本：

```text
scripts/
├── 08_generate_transaction_features.py
├── 09_generate_graph_features.py
└── 10_merge_model_features.py
```

## 二、风险识别模型

### 1. 基线模型

至少包括：

- 规则评分模型；
- Logistic Regression；
- Random Forest；
- LightGBM 或 XGBoost。

### 2. 嫌疑人账户主模型

核心目标：

> 区分嫌疑人账户与非嫌疑人账户。

应交付：

- 模型训练代码；
- 超参数配置；
- 类别不平衡处理；
- 特征选择；
- 概率校准；
- 模型保存与推理代码；
- 风险分数输出。

建议输出字段：

```text
account_id
suspect_probability
risk_score
risk_level
risk_rank
top_risk_factors
```

### 3. 广义风险账户辅助模型

预测“嫌疑人或受害人”与“其他账户”的差异，用于辅助验证特征有效性、风险筛查能力和模型稳定性。必须明确其为辅助模型，不能用其指标替代嫌疑人识别指标。

### 4. 两阶段风险识别模型

建议交付：

1. 风险账户筛查模型；
2. 嫌疑人与受害人区分模型；
3. 最终嫌疑人概率融合模块；
4. 直接嫌疑人二分类模型，用作对照。

### 5. 图模型或图嵌入对比实验

可以包含：

- Node2Vec；
- DeepWalk；
- GraphSAGE；
- GCN；
- 图嵌入与 LightGBM 融合。

应定位为探索性对比模型，而不是唯一核心模型。

建议目录：

```text
src/models/
├── rule_baseline.py
├── logistic_baseline.py
├── tree_baseline.py
├── suspect_classifier.py
├── broad_risk_classifier.py
├── two_stage_classifier.py
├── graph_embedding_model.py
└── probability_calibration.py
```

## 三、可疑关联账户与资金链路分析

### 1. 关联账户发现

针对每个高风险账户输出：

- Top 20 可疑关联账户；
- 关联方向；
- 交易次数；
- 累计金额；
- 最近交易时间；
- 关联账户风险分数；
- 关联强度；
- 关联原因。

建议输出：

```text
outputs/link_analysis/top_related_accounts.csv
```

### 2. 可疑路径挖掘

至少支持：

- 一跳、二跳、三跳路径；
- 指定时间窗口路径；
- 按路径风险排序。

每条路径应包含：

- 起始账户；
- 中转账户；
- 终止账户；
- 交易时间；
- 交易金额；
- 路径长度；
- 路径风险分数；
- 风险触发原因。

建议输出：

```text
outputs/link_analysis/suspicious_paths.csv
```

### 3. 典型资金模式识别

至少包括：

- 多账户向单账户汇聚；
- 单账户向多账户分散；
- 收款后短时间转出；
- 高频小额拆分；
- 大额异常转账；
- 高频重复交易；
- 多层中转；
- 双向循环交易；
- 社区内部密集交易；
- 高风险账户邻域聚集。

每种模式应包含：

- 识别规则；
- 参数阈值；
- 命中账户；
- 命中交易；
- 证据说明。

### 4. 链路评分模块

综合考虑：

- 节点风险；
- 金额异常；
- 时间紧迫性；
- 结构异常；
- 关联账户异常；
- 多跳传播风险。

最终形成路径风险分数和排序结果。
