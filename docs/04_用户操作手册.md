# 用户操作手册

## 安装

已有环境：`conda activate jk_new`。新环境：`conda env create -f environment.yml`。

## 全流程

在项目根目录执行 `python scripts/run_all_pipeline.py`。原始 Excel 位于项目内的 `data/raw`，流水线保持只读。

## 启动界面

双击 `run_app.bat`，或执行 `set PYTHONPATH=%CD%\src` 后运行 `streamlit run app.py`。浏览器访问 `http://127.0.0.1:8501`。

界面包含风险总览、风险账户、资金图谱、可疑路径、典型案例、模型与口径六个页面。资金图谱支持按日期、金额、方向、跳数和风险等级筛选；调整条件后点击“生成 / 刷新资金图谱”，系统会显示生成进度并缓存重复查询。

## 甲方盲审

打开 `outputs/manual_review/链路盲审表.xlsx`，由 A/B 两位审核人分别填写黄色区域。回填并保存后执行 `python scripts/aggregate_manual_review.py`。

## 验收

执行 `python scripts/verify_delivery.py`，包括 `PATH_CHECK` 在内的全部检查应为 PASS。

更详细的安装、成果说明、运行入口、证据索引和常见问题见根目录 `README.md`。
