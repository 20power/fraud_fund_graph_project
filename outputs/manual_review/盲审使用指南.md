# 甲方关联链路盲审使用指南

## 目的

本盲审用于验证关联链路解释是否符合人工研判逻辑。盲审结果独立于嫌疑人主模型指标，不替代模型测试集结果，也不构成涉诈认定。

## 审核方式

1. 由两名审核人员分别填写工作簿中的“审核人A”和“审核人B”席位。
2. 审核期间不要打开 `blind_review_key.csv`，以免真实账户、标签和模型信息影响判断。
3. 只填写黄色列，优先使用下拉选项；选择“不合理”或“证据不足”时请补充原因。
4. 无法基于现有证据判断时选择“无法判断”，不要猜测。
5. 保存回填后的工作簿，并运行：`python scripts/aggregate_manual_review.py`。

## 统计口径

- 解释合理率 =（合理 + 基本合理）/ 有效合理性评价。
- 证据充分率 =（充分 + 基本充分）/ 有效证据评价。
- 空白和“无法判断”不进入对应指标分母。
- 解释合理率 70% 是本项目参考目标；最终是否接受仍由甲方结合样本量、审核一致性和业务要求判断。

## 文件管理

`blind_review_key.csv` 是解除盲态的内部映射表，须与甲方评分表分开传递和保管。模型输出仅作辅助研判，不代表账户已被认定涉诈。
